# 🧠 Frontend Quiz

Welcome to **Frontend Quiz!** A sleek, interactive web app designed to test your knowledge of frontend development topics. Built with modern web technologies and a focus on clean UI, modular components, and responsive design.

## 🚀 Live Demo
Check it out here: [frontend-quiz-black-gamma.vercel.app](https://frontend-quiz-black-gamma.vercel.app/)

## 📚 Features
- ✨ Subject-based quiz selection
- 🎯 Multiple-choice questions with instant feedback
- 🎨 Theme-aware styling (light/dark mode)
- 📱 Responsive layout for mobile and desktop
- ⚙️ Modular React components for scalability

## 🛠️ Tech Stack
- **React** with functional components
- **CSS Modules**
- **React Context** for theme and state management
- **React Router** for routing
- **Vercel** for deployment
